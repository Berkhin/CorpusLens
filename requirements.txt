# Flickr8k Explorer — Python dependencies (offline data pipeline).

# HARDWARE CEILING — READ BEFORE CHANGING ANY PIN.
# The target machine is macOS on Intel (x86_64). Two upstream projects stopped
# publishing macOS x86_64 wheels, which fixes the top of this dependency tree:
#
#   * torch   — last macOS x86_64 wheel is 2.2.2 (verified on PyPI: 2.3.0+ ship
#               no macosx_*_x86_64 artifact). 2.2.2 supports cp38–cp312 only,
#               hence Python 3.12 — 3.13/3.14 cannot install torch on this Mac.
#   * lancedb — last macOS x86_64 wheel is 0.25.3
#               (lancedb-0.25.3-cp39-abi3-macosx_10_15_x86_64.whl).
#
# torch 2.2.2 is compiled against the NumPy 1.x C ABI, so NumPy must stay <2.
# Everything else is free to float and is pinned here for reproducibility.
#
# Verified resolved + imported on this machine:
#   Python 3.12.13, x86_64, Intel Core i9-9980HK.
#
# Install (CPU wheels are the default on macOS — no --index-url needed):
#   uv venv backend/.venv --python 3.12
#   uv pip install --python backend/.venv/bin/python -r requirements.txt
